CG

CG is a personal computing environment I am building for myself: a small language, and a desktop written in it. Windows, an editor, mail, feeds, a calendar, maps, music, notes and finances are all programs in that one language, and all of it can be inspected and changed while it runs.

It runs on my own computer. It is not a service, and nobody else has an account on it.

The calendar can show events from Google Calendar next to my own tasks. It only reads them. It never creates, changes or deletes anything in Google Calendar.
